# Monk character and animations

All CC0 1.0 Universal (public domain): https://creativecommons.org/publicdomain/zero/1.0/

- `monk.glb` -- a MakeHuman character built with MPFB 2 (makehumancommunity.org),
  wearing the CC0 "donitz_monk_robe" and its hood from the MakeHuman community
  asset pack *suits02*, with the MPFB `game_engine` rig. Textures resized to
  1024 px. Characters made with MakeHuman are CC0.
- `ual_animations.glb` -- *Universal Animation Library* (standard version) by
  Quaternius (quaternius.com), CC0.

The bone maps (`*_bonemap.tres`) retarget both skeletons to Godot's humanoid
profile on import, so the animations play on the monk.
