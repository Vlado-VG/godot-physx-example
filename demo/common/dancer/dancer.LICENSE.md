# Dancer character

CC0 1.0 Universal (public domain): https://creativecommons.org/publicdomain/zero/1.0/

- `dancer.glb` -- a MakeHuman character built with MPFB 2 (makehumancommunity.org),
  wearing the CC0 "toigo_camisole_dress_with_full_skirt" from the MakeHuman
  community asset pack *dress01*, with the MPFB `game_engine` rig. The body is
  exported whole (not masked under the dress) so nothing is missing when the
  skirt swings away from the legs. Textures resized to 1024 px. Characters
  made with MakeHuman are CC0.

It shares the monk's bone map (`../monk/monk_bonemap.tres`, same rig) and plays
the same retargeted animation library (`../monk/ual_animations.glb`).
